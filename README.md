# HGSS-Automatic-Shiny-Hunter
I created this for a school project to run using the DeSmuME Pokemon HeartGold rom to automatically hunt for one of the 3 starters. I welcome changes and reccomendations as this was my first attempt at sharing anything here as well as my first time using Java. I used fixed xy coordinates for the specific color check on my computer this may cause issues so I fully intend to make a revision for it to work but I still have alot to learn to figure that out. My scale is at 150% with a display resolution 2560 x 1440 with the DESmuME emulator all the way to the right fit to the corner of my screen expanded so the top of the emulator is in the corner and the bottom is even with my task bar. I'm unsure if that will help anyone or if it will run on your computer so please let me know I value  feedback.
